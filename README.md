# 🔵 LLM Defense Gateway

Phase 2 of a 3-phase AI AppSec build — defenses for every exploit in [`llm-redteam-framework`](https://github.com/SkSahil-lab/llm-redteam-framework).

Each `defense_dayNN.py` is a standalone Python class. Each `test_dayNN.py` runs the *exact* attack payloads from the matching Phase 1 day against it — proof, not description.

Run any day: `python test_dayNN.py`

See [DEFENSE_SCORECARD.md](./DEFENSE_SCORECARD.md) for progress.
